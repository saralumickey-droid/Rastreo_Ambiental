# RNF-034 — Recuperación ante fallos

**Tipo:** Requisito No Funcional de Recuperabilidad

## Descripción
El sistema debe contar con procedimientos para recuperar el servicio tras un incidente.

## Requisitos Específicos

RNF-034.1 — El objetivo de recuperación del servicio será de máximo 10 minutos para fallos cubiertos por el procedimiento de recuperación.

RNF-034.2 — Los respaldos y procedimientos de restauración deben probarse periódicamente.

## Verificación
Realizar un ejercicio de recuperación y registrar el tiempo real alcanzado.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
