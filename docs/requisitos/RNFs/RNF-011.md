# RNF-011 — Facilidad de aprendizaje

**Tipo:** Requisito No Funcional de Usabilidad

## Descripción
El sistema debe ser comprensible para usuarios con conocimientos básicos de navegación web.

## Requisitos Específicos

RNF-011.1 — Los formularios deben incluir etiquetas visibles y formatos de entrada claros.

RNF-011.2 — Los campos obligatorios y los errores de validación deben identificarse de forma comprensible.

## Verificación
Verificar los formularios y observar si los usuarios completan tareas frecuentes sin ayuda.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
