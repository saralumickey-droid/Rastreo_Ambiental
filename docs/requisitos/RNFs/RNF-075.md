# RNF-075 — Identificadores únicos

**Tipo:** Requisito No Funcional de Integridad

## Descripción
Los registros deben contar con identificadores únicos y estables para evitar colisiones.

## Requisitos Específicos

RNF-075.1 — Se podrán utilizar UUID para entidades distribuidas o cuando facilite la integración entre servicios.

RNF-075.2 — La base de datos debe aplicar restricciones de unicidad a los identificadores.

## Verificación
Revisar el esquema y comprobar las restricciones de clave primaria y unicidad.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
