# RNF-058 — Procesamiento de reportes

**Tipo:** Requisito No Funcional de Rendimiento

## Descripción
El sistema debe soportar el procesamiento sostenido de reportes ambientales dentro de la capacidad definida.

## Requisitos Específicos

RNF-058.1 — El objetivo de carga será procesar al menos 100 reportes por minuto en el entorno de referencia definido.

RNF-058.2 — La prueba debe verificar que no haya pérdida ni duplicación de reportes y registrar la latencia.

## Verificación
Ejecutar una prueba de carga con reportes simulados y documentar recursos y resultados.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
