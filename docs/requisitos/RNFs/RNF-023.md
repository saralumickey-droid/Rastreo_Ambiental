# RNF-023 — Manejo de pérdida de señal

**Tipo:** Requisito No Funcional de Confiabilidad

## Descripción
El sistema debe responder de forma controlada ante la pérdida de señal o de conexión.

## Requisitos Específicos

RNF-023.1 — Los formularios deben conservar temporalmente los datos no enviados cuando sea seguro hacerlo.

RNF-023.2 — Las solicitudes fallidas deben permitir reintento y evitar duplicados cuando la operación se repita.

## Verificación
Simular pérdida de red durante consulta y envío de reportes.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
