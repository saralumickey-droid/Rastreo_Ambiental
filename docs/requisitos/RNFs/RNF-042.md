# RNF-042 — Accesibilidad WCAG

**Tipo:** Requisito No Funcional de Accesibilidad

## Descripción
La interfaz debe seguir criterios de accesibilidad WCAG 2.1 nivel AA en las pantallas principales.

## Requisitos Específicos

RNF-042.1 — El texto normal debe mantener una relación de contraste mínima de 4.5:1.

RNF-042.2 — Los controles principales deben poder operarse con teclado y tener nombres accesibles.

RNF-042.3 — Los errores de formulario deben comunicarse de forma comprensible a tecnologías de asistencia.

## Verificación
Ejecutar revisión automática y manual de accesibilidad en pantallas representativas.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
