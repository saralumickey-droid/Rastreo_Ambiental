# RNF-038 — Precisión del GPS

**Tipo:** Requisito No Funcional de Geolocalización

## Descripción
El sistema debe mostrar la precisión que permita el dispositivo, sin prometer una exactitud que dependa de factores externos.

## Requisitos Específicos

RNF-038.1 — El objetivo de precisión de 10 metros solo se considerará cumplido cuando las condiciones del dispositivo y la señal lo permitan.

RNF-038.2 — Cuando la precisión informada sea inferior, la interfaz debe señalar que la ubicación es aproximada.

## Verificación
Probar en distintos entornos y registrar la precisión informada por el dispositivo.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
