# RNF-078 — Mensajería para alertas

**Tipo:** Requisito No Funcional de Interoperabilidad

## Descripción
La arquitectura debe permitir procesar alertas de forma desacoplada si el volumen o la confiabilidad lo requieren.

## Requisitos Específicos

RNF-078.1 — Si se incorpora un broker de mensajes, los consumidores deben manejar reintentos y evitar procesar un mismo evento más de una vez de forma dañina.

RNF-078.2 — La entrega de alertas debe poder monitorearse y los mensajes fallidos deben quedar identificados para su revisión.

## Verificación
Validar la estrategia de mensajería si se implementa; si no existe broker, registrar este requisito como pendiente o no aplicable.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
