# RNF-017 — Disponibilidad del servicio

**Tipo:** Requisito No Funcional de Disponibilidad

## Descripción
El sistema debe mantener disponible sus funciones principales durante la operación prevista.

## Requisitos Específicos

RNF-017.1 — La disponibilidad mensual objetivo del servicio será de al menos 95 %, excluyendo mantenimientos programados comunicados previamente.

RNF-017.2 — Los periodos de indisponibilidad deben registrarse para calcular la disponibilidad real.

## Verificación
Calcular la disponibilidad mensual a partir de registros de monitoreo.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
