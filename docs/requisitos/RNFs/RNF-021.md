# RNF-021 — Escalabilidad de conexiones

**Tipo:** Requisito No Funcional de Escalabilidad

## Descripción
La arquitectura debe permitir aumentar la capacidad de procesamiento cuando crezca la cantidad de usuarios.

## Requisitos Específicos

RNF-021.1 — Los límites de conexiones y recursos deben configurarse de forma explícita.

RNF-021.2 — El crecimiento de carga debe evaluarse mediante pruebas antes de aumentar la capacidad de producción.

## Verificación
Ejecutar pruebas de carga y revisar métricas de uso de CPU, memoria y conexiones.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
