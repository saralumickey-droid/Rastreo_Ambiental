# RNF-033 — Latencia de API

**Tipo:** Requisito No Funcional de Rendimiento

## Descripción
La API debe responder con baja latencia para las operaciones frecuentes.

## Requisitos Específicos

RNF-033.1 — Los endpoints frecuentes deben alcanzar una latencia inferior a 200 ms en condiciones normales de prueba, sin contar dependencias externas lentas.

RNF-033.2 — Las mediciones deben registrar percentiles y tamaño de muestra, no solo un promedio.

## Verificación
Ejecutar pruebas repetibles sobre endpoints de consulta y documentar el entorno.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
