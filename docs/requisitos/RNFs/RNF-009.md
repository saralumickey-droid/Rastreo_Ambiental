# RNF-009 — Entrega de notificaciones

**Tipo:** Requisito No Funcional de Rendimiento

## Descripción
Las notificaciones deben generarse y entregarse en un tiempo razonable según el canal disponible.

## Requisitos Específicos

RNF-009.1 — Las notificaciones internas deben estar disponibles para consulta inmediatamente después de registrarse el evento, salvo demoras técnicas documentadas.

RNF-009.2 — Si se utiliza un servicio externo, el sistema debe manejar fallos y reintentos sin crear notificaciones duplicadas.

## Verificación
Probar la generación de alertas, los reintentos y los escenarios de indisponibilidad del proveedor.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
