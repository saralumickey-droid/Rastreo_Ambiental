# RNF-010 — Interfaz intuitiva

**Tipo:** Requisito No Funcional de Usabilidad

## Descripción
La interfaz debe permitir que una persona con conocimientos básicos de tecnología comprenda las funciones principales.

## Requisitos Específicos

RNF-010.1 — Las acciones principales deben tener nombres claros y consistentes.

RNF-010.2 — Las tareas frecuentes deben poder completarse sin instrucciones externas extensas.

## Verificación
Realizar pruebas de usabilidad con usuarios representativos y registrar dificultades.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
