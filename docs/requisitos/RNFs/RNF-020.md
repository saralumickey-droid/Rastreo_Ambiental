# RNF-020 — Mantenimiento y corrección

**Tipo:** Requisito No Funcional de Mantenibilidad

## Descripción
La arquitectura y el código deben facilitar la identificación y corrección de defectos.

## Requisitos Específicos

RNF-020.1 — El código debe organizarse por responsabilidades y módulos claramente identificados.

RNF-020.2 — Los cambios relevantes deben contar con pruebas y documentación técnica actualizada.

## Verificación
Revisar la estructura del proyecto, las pruebas automatizadas y la documentación.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
