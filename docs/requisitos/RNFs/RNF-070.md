# RNF-070 — Modo de ahorro de energía

**Tipo:** Requisito No Funcional de Eficiencia

## Descripción
Las funciones de seguimiento deben evitar actividad innecesaria cuando el dispositivo limita el consumo de energía.

## Requisitos Específicos

RNF-070.1 — La aplicación debe reducir tareas de actualización no esenciales cuando el navegador o sistema limite la actividad en segundo plano.

RNF-070.2 — Si no es posible detectar directamente el modo de ahorro, debe respetar las limitaciones impuestas por el sistema.

## Verificación
Probar el comportamiento con restricciones de segundo plano y ahorro de energía.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
