# RNF-002 — Protección de datos personales

**Tipo:** Requisito No Funcional de Privacidad

## Descripción
El sistema debe tratar los datos personales de los usuarios de forma limitada, segura y acorde con las finalidades de Rastreo Ambiental.

## Requisitos Específicos

RNF-002.1 — Solo deben recopilarse los datos personales necesarios para las funciones del sistema.

RNF-002.2 — El acceso a datos personales debe limitarse a usuarios y procesos autorizados.

RNF-002.3 — La información de ubicación no debe mostrarse a otros usuarios salvo que sea necesaria para una función autorizada y exista una base válida para hacerlo.

## Verificación
Revisar los formularios, permisos y pantallas donde se consultan datos personales.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
