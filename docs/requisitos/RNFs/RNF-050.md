# RNF-050 — Gestión segura de claves API

**Tipo:** Requisito No Funcional de Seguridad

## Descripción
Las claves de servicios externos deben protegerse y administrarse fuera del código fuente.

## Requisitos Específicos

RNF-050.1 — Las claves API deben cargarse desde variables de entorno o un gestor de secretos.

RNF-050.2 — Las claves no deben exponerse en el frontend si permiten operaciones privilegiadas.

RNF-050.3 — Las claves comprometidas deben poder revocarse y reemplazarse.

## Verificación
Buscar secretos en el repositorio y revisar la configuración de despliegue.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
