# RNF-046 — Tiempo de baja

**Tipo:** Requisito No Funcional de Disponibilidad

## Descripción
Las interrupciones planificadas deben ser breves y comunicarse cuando afecten el servicio.

## Requisitos Específicos

RNF-046.1 — El objetivo de indisponibilidad por mantenimiento planificado será inferior a 2 minutos por intervención cuando la infraestructura lo permita.

RNF-046.2 — La duración real de cada intervención debe registrarse.

## Verificación
Revisar los registros de despliegue y mantenimiento; validar la viabilidad con el proveedor.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
