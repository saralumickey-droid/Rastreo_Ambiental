# RNF-018 — Continuidad del servicio

**Tipo:** Requisito No Funcional de Disponibilidad

## Descripción
El sistema debe reducir las interrupciones y permitir recuperar el servicio después de fallos.

## Requisitos Específicos

RNF-018.1 — Los errores de servicios externos deben manejarse sin bloquear innecesariamente toda la aplicación.

RNF-018.2 — Cuando una función no esté disponible, el usuario debe recibir un aviso claro y no perder datos ya confirmados.

## Verificación
Simular fallos de conexión y de servicios externos en un entorno de pruebas.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
