# RNF-047 — Tecnologías con soporte vigente

**Tipo:** Requisito No Funcional de Mantenibilidad

## Descripción
Las tecnologías principales deben contar con soporte y actualizaciones de seguridad vigentes.

## Requisitos Específicos

RNF-047.1 — Las versiones de ejecución y dependencias críticas deben mantenerse en versiones con soporte del fabricante o comunidad.

RNF-047.2 — Las excepciones por compatibilidad deben documentarse y revisarse periódicamente.

## Verificación
Revisar versiones de runtime, frameworks y políticas de actualización.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
