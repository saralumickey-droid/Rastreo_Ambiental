# RNF-066 — Detección de tráfico inusual

**Tipo:** Requisito No Funcional de Monitoreo

## Descripción
El sistema debe permitir identificar patrones anómalos de solicitudes que puedan afectar su seguridad o rendimiento.

## Requisitos Específicos

RNF-066.1 — Los eventos que superen umbrales configurados deben registrarse y generar una alerta operativa cuando corresponda.

RNF-066.2 — La detección debe evitar incluir datos personales innecesarios en las alertas.

## Verificación
Simular picos de solicitudes y verificar registros y alertas.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
