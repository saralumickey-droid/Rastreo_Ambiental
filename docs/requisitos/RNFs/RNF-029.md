# RNF-029 — Consumo de batería

**Tipo:** Requisito No Funcional de Eficiencia

## Descripción
Las funciones móviles deben evitar el uso innecesario de batería, especialmente al obtener ubicación.

## Requisitos Específicos

RNF-029.1 — La ubicación debe solicitarse únicamente con la frecuencia necesaria para la función activa.

RNF-029.2 — El seguimiento debe detenerse o reducirse cuando el usuario abandone la función que lo necesita, según el diseño aprobado.

## Verificación
Medir el comportamiento de seguimiento y revisar que no existan consultas de ubicación innecesarias.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
