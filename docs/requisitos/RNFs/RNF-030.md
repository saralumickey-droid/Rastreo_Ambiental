# RNF-030 — Consumo de datos móviles

**Tipo:** Requisito No Funcional de Eficiencia

## Descripción
La aplicación debe reducir transferencias innecesarias para facilitar su uso con planes de datos limitados.

## Requisitos Específicos

RNF-030.1 — Las imágenes y respuestas de API deben evitar contenido redundante.

RNF-030.2 — Los recursos estáticos que no cambien frecuentemente deben poder aprovechar la caché del navegador.

## Verificación
Medir el tráfico de red durante tareas representativas.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
