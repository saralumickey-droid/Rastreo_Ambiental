# RNF-028 — Canal de soporte técnico

**Tipo:** Requisito No Funcional de Soporte

## Descripción
El sistema debe ofrecer un medio identificable para comunicar problemas o solicitar ayuda.

## Requisitos Específicos

RNF-028.1 — El canal de soporte debe mostrar información de contacto vigente o un formulario funcional.

RNF-028.2 — Cuando se registre una solicitud, debe mostrarse una confirmación de recepción.

## Verificación
Comprobar que el canal esté visible y que las solicitudes generen confirmación.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
