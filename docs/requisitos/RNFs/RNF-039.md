# RNF-039 — Copias de seguridad

**Tipo:** Requisito No Funcional de Confiabilidad

## Descripción
La información operativa debe contar con copias de seguridad que permitan restaurarla.

## Requisitos Específicos

RNF-039.1 — La base de datos debe respaldarse automáticamente al menos una vez al día.

RNF-039.2 — Los respaldos deben almacenarse con acceso restringido y comprobarse mediante pruebas de restauración.

## Verificación
Revisar el historial de respaldos y realizar una restauración de prueba.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
