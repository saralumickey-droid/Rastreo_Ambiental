# RNF-043 — Registros sin datos sensibles

**Tipo:** Requisito No Funcional de Seguridad

## Descripción
Los logs deben permitir investigar errores sin divulgar información confidencial.

## Requisitos Específicos

RNF-043.1 — Los logs no deben guardar contraseñas, tokens completos ni datos personales innecesarios.

RNF-043.2 — Los eventos relevantes deben incluir fecha, tipo de evento y contexto técnico mínimo, con acceso restringido.

## Verificación
Inspeccionar registros de autenticación, errores y operaciones administrativas.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
