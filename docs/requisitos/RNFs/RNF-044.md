# RNF-044 — Diseño responsive para tabletas

**Tipo:** Requisito No Funcional de Compatibilidad

## Descripción
La interfaz debe adaptarse a tabletas en orientación vertical y horizontal.

## Requisitos Específicos

RNF-044.1 — Las pantallas principales deben conservar legibilidad y controles accesibles en tamaños de tableta.

RNF-044.2 — Las tablas, mapas y formularios no deben provocar desbordamientos horizontales innecesarios.

## Verificación
Probar los módulos principales en tamaños de tableta y ambas orientaciones.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
