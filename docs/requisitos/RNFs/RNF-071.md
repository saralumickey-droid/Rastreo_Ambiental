# RNF-071 — Tamaño de fuente

**Tipo:** Requisito No Funcional de Accesibilidad

## Descripción
La interfaz debe respetar las preferencias de legibilidad y ampliación de texto del usuario.

## Requisitos Específicos

RNF-071.1 — El texto debe poder ampliarse sin ocultar controles ni impedir las tareas principales.

RNF-071.2 — Los componentes deben usar unidades y estilos que faciliten el ajuste de tamaño.

## Verificación
Aumentar el tamaño del texto y comprobar que las pantallas sigan siendo utilizables.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
