# RNF-074 — Compresión de respuestas

**Tipo:** Requisito No Funcional de Rendimiento

## Descripción
Las respuestas HTTP compatibles deben comprimirse para reducir el volumen de transferencia.

## Requisitos Específicos

RNF-074.1 — La compresión Gzip o Brotli debe habilitarse en el servidor o proxy para respuestas compatibles.

RNF-074.2 — Los recursos ya comprimidos no deben volver a comprimirse de forma ineficiente.

## Verificación
Inspeccionar cabeceras HTTP y medir el tamaño de respuestas antes y después de la compresión.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
