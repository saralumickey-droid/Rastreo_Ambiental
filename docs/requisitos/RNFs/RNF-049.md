# RNF-049 — Detección de zona horaria

**Tipo:** Requisito No Funcional de Compatibilidad

## Descripción
Las fechas y horas deben mostrarse de forma coherente con la zona horaria aplicable.

## Requisitos Específicos

RNF-049.1 — Los eventos deben almacenarse con una referencia temporal inequívoca y mostrarse según la zona horaria configurada para el usuario o servicio.

RNF-049.2 — Si no puede detectarse la zona horaria, se debe usar una zona predeterminada documentada.

## Verificación
Probar registro y visualización de eventos en distintas zonas horarias.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
