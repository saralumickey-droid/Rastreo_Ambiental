# RNF-052 — Caché de rutas y mapas

**Tipo:** Requisito No Funcional de Rendimiento

## Descripción
El sistema debe evitar descargar repetidamente información de rutas que no haya cambiado.

## Requisitos Específicos

RNF-052.1 — Los datos de mapa y rutas podrán almacenarse en caché durante un periodo definido, siempre que se invalide o actualice la caché al cambiar la información.

RNF-052.2 — La caché no debe provocar que se muestre como actual una posición GPS antigua.

## Verificación
Verificar políticas de caché y probar la actualización de rutas y posiciones.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
