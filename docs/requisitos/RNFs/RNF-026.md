# RNF-026 — Privacidad de ubicación

**Tipo:** Requisito No Funcional de Privacidad

## Descripción
El acceso a la ubicación del usuario debe respetar su privacidad y los permisos del dispositivo.

## Requisitos Específicos

RNF-026.1 — La aplicación debe solicitar permiso antes de acceder a la ubicación del dispositivo.

RNF-026.2 — Si el permiso es denegado, el usuario debe poder continuar utilizando las funciones que no dependan de su ubicación.

## Verificación
Probar permisos concedidos, denegados y revocados.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
