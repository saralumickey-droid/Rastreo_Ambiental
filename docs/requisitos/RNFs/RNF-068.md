# RNF-068 — Transacciones ACID

**Tipo:** Requisito No Funcional de Integridad

## Descripción
Las operaciones que modifican datos relacionados deben preservar la consistencia transaccional.

## Requisitos Específicos

RNF-068.1 — Las operaciones que requieran atomicidad deben ejecutarse dentro de transacciones de base de datos.

RNF-068.2 — Si una operación falla, los cambios parciales deben revertirse cuando corresponda.

## Verificación
Probar operaciones que modifiquen varias entidades y simular fallos intermedios.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
