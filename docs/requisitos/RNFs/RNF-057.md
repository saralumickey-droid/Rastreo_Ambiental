# RNF-057 — Límite de peticiones

**Tipo:** Requisito No Funcional de Seguridad

## Descripción
La API debe limitar peticiones para reducir abuso y proteger la disponibilidad.

## Requisitos Específicos

RNF-057.1 — Los endpoints sensibles deben contar con límites de peticiones configurables por IP, usuario o ambos.

RNF-057.2 — Al exceder el límite, la API debe responder con HTTP 429 y evitar registrar información sensible innecesaria.

## Verificación
Realizar solicitudes repetidas en un entorno de prueba y comprobar el límite aplicado.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
