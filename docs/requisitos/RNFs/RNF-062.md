# RNF-062 — Integración con APIs de mapas

**Tipo:** Requisito No Funcional de Interoperabilidad

## Descripción
La integración cartográfica debe usar servicios documentados y gestionar sus límites de disponibilidad.

## Requisitos Específicos

RNF-062.1 — Las llamadas a servicios cartográficos deben ajustarse a sus condiciones de uso, límites y requisitos de atribución.

RNF-062.2 — Si un proveedor de mapas falla, la aplicación debe mostrar un aviso y conservar disponibles las funciones que no dependan del mapa.

## Verificación
Verificar la integración, la atribución requerida y el comportamiento ante errores del proveedor.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
