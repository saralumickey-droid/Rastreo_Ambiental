# RNF-063 — Carga del dashboard

**Tipo:** Requisito No Funcional de Rendimiento

## Descripción
Los paneles deben presentar sus indicadores principales en un tiempo aceptable.

## Requisitos Específicos

RNF-063.1 — El dashboard debe mostrar su contenido principal en menos de 5 segundos en el entorno de referencia definido.

RNF-063.2 — Las consultas de indicadores deben evitar cargar datos innecesarios y permitir paginación o filtros cuando aplique.

## Verificación
Medir la carga con un volumen de datos de prueba representativo.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
