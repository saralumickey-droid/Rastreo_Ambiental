# RNF-025 — Actualización de posición

**Tipo:** Requisito No Funcional de Geolocalización

## Descripción
La ubicación de los camiones debe actualizarse con una frecuencia definida por la disponibilidad del GPS y la conectividad.

## Requisitos Específicos

RNF-025.1 — Cada posición recibida debe incluir fecha y hora para distinguir datos recientes de datos antiguos.

RNF-025.2 — Si la posición deja de actualizarse, la interfaz debe indicar la hora de la última actualización.

## Verificación
Simular posiciones sucesivas y pérdida temporal de datos GPS.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
