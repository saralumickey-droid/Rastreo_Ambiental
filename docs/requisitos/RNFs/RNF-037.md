# RNF-037 — Compatibilidad iOS

**Tipo:** Requisito No Funcional de Compatibilidad

## Descripción
Si se desarrolla una aplicación móvil nativa o híbrida, debe ser compatible con iOS 13 o superior.

## Requisitos Específicos

RNF-037.1 — Las funciones soportadas deben probarse en versiones de iOS dentro del rango objetivo.

RNF-037.2 — Si el producto es exclusivamente web, la compatibilidad se evaluará en Safari móvil y este criterio nativo será no aplicable.

## Verificación
Probar en dispositivos o simuladores iOS dentro del rango objetivo.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
