# RNF-059 — Normalización de base de datos

**Tipo:** Requisito No Funcional de Integridad

## Descripción
El modelo relacional debe reducir duplicidad y anomalías de actualización.

## Requisitos Específicos

RNF-059.1 — Las tablas transaccionales deben diseñarse hasta tercera forma normal cuando corresponda al modelo relacional.

RNF-059.2 — Las excepciones justificadas por rendimiento deben documentarse y proteger la integridad mediante restricciones o procesos controlados.

## Verificación
Revisar el modelo entidad-relación y las dependencias funcionales.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
