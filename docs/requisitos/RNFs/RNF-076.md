# RNF-076 — Almacenamiento de archivos en nube

**Tipo:** Requisito No Funcional de Escalabilidad

## Descripción
Los archivos de reportes deben almacenarse de forma segura y separada de los datos transaccionales cuando la infraestructura lo requiera.

## Requisitos Específicos

RNF-076.1 — Si se utiliza almacenamiento de objetos compatible con S3, los contenedores deben ser privados por defecto.

RNF-076.2 — El acceso a archivos debe controlarse mediante permisos o enlaces temporales cuando corresponda.

## Verificación
Revisar la configuración de permisos, accesos y políticas de almacenamiento del proveedor elegido.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
