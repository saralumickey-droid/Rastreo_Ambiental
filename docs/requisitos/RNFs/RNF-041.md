# RNF-041 — Arquitectura mantenible

**Tipo:** Requisito No Funcional de Mantenibilidad

## Descripción
La arquitectura debe separar responsabilidades para facilitar cambios y corrección de errores.

## Requisitos Específicos

RNF-041.1 — La interfaz, las reglas de negocio y el acceso a datos deben mantenerse separados según la arquitectura del proyecto.

RNF-041.2 — Las funciones críticas deben contar con pruebas que reduzcan el riesgo de regresiones.

## Verificación
Revisar la organización de carpetas, dependencias y pruebas automatizadas.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
