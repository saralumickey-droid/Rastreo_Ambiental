# RNF-048 — Indexación geográfica

**Tipo:** Requisito No Funcional de Rendimiento

## Descripción
Las consultas de ubicación deben optimizarse para responder con eficiencia a búsquedas geográficas.

## Requisitos Específicos

RNF-048.1 — Si la base de datos almacena un volumen significativo de coordenadas, se evaluará el uso de índices geoespaciales adecuados al motor seleccionado.

RNF-048.2 — La estructura de índices debe validarse mediante planes de ejecución y pruebas de consulta.

## Verificación
Medir consultas de proximidad y revisar planes de ejecución de la base de datos.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
