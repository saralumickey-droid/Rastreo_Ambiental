# RNF-001 — Seguridad y protección de datos

**Tipo:** Requisito No Funcional de Seguridad

## Descripción
El sistema debe proteger la información sensible almacenada, evitando su exposición ante accesos no autorizados.

## Requisitos Específicos

RNF-001.1 — La información sensible almacenada debe protegerse mediante cifrado en reposo cuando la tecnología de almacenamiento lo permita.

RNF-001.2 — Las contraseñas no deben almacenarse en texto plano; deben procesarse con un algoritmo de hash de contraseñas resistente y con sal individual.

RNF-001.3 — Las claves, tokens y credenciales de servicios deben mantenerse en variables de entorno o en un gestor de secretos, nunca en el código fuente.

RNF-001.4 — Los registros del sistema no deben incluir contraseñas, tokens completos ni otros datos personales innecesarios.

## Verificación
Verificar configuración de almacenamiento, método de hash y registros; comprobar que no se exponen secretos en el repositorio.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
