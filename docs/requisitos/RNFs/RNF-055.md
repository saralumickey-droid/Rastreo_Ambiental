# RNF-055 — Ubicación predeterminada ante fallo GPS

**Tipo:** Requisito No Funcional de Usabilidad

## Descripción
Si no se obtiene la ubicación del dispositivo, el mapa debe seguir siendo utilizable mediante una ubicación de referencia.

## Requisitos Específicos

RNF-055.1 — Ante un fallo GPS, el mapa debe mostrar una ubicación predeterminada configurada y claramente identificada como referencia.

RNF-055.2 — La ubicación predeterminada no debe presentarse como la ubicación real del usuario.

## Verificación
Desactivar permisos de ubicación y verificar el mensaje y el centro del mapa.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
