# RNF-040 — Escalabilidad horizontal

**Tipo:** Requisito No Funcional de Escalabilidad

## Descripción
La infraestructura debe permitir agregar instancias de aplicación si el crecimiento de demanda lo requiere.

## Requisitos Específicos

RNF-040.1 — Los componentes que se escalen horizontalmente no deben depender de estado de sesión almacenado exclusivamente en memoria local.

RNF-040.2 — La escalabilidad horizontal queda condicionada a las capacidades del servicio de alojamiento seleccionado.

## Verificación
Revisar arquitectura y realizar una prueba en infraestructura que permita múltiples instancias.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
