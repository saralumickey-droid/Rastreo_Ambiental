# RNF-007 — Tiempo de respuesta de consultas

**Tipo:** Requisito No Funcional de Rendimiento

## Descripción
Las consultas habituales deben responder con rapidez para permitir la consulta de rutas, reportes y datos operativos.

## Requisitos Específicos

RNF-007.1 — Las consultas frecuentes de la API deberían responder en menos de 200 ms en condiciones normales, excluyendo servicios externos y operaciones de larga duración.

RNF-007.2 — La interfaz debe indicar cuando una consulta está en curso y presentar un resultado o un mensaje de error comprensible.

## Verificación
Medir endpoints representativos con datos de prueba y documentar las condiciones de medición.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
