# RNF-024 — Precisión de ubicación

**Tipo:** Requisito No Funcional de Geolocalización

## Descripción
La aplicación debe presentar la ubicación con la precisión que informe el dispositivo o el proveedor geográfico.

## Requisitos Específicos

RNF-024.1 — Cuando el dispositivo suministre la precisión estimada, esta debe utilizarse para advertir si la ubicación es aproximada.

RNF-024.2 — El sistema no debe presentar una ubicación estimada como exacta.

## Verificación
Comparar la precisión informada por el dispositivo con la ubicación mostrada en el mapa.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
