# RNF-032 — Hash de contraseñas

**Tipo:** Requisito No Funcional de Seguridad

## Descripción
Las contraseñas deben almacenarse de manera que no puedan recuperarse como texto original.

## Requisitos Específicos

RNF-032.1 — Las contraseñas deben procesarse con un algoritmo dedicado al hash de contraseñas, con sal única por contraseña.

RNF-032.2 — El proceso de autenticación debe comparar hashes de forma segura y nunca registrar contraseñas.

## Verificación
Revisar la implementación de autenticación y comprobar el contenido almacenado en la base de datos.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
