# RNF-031 — Comunicación segura HTTPS

**Tipo:** Requisito No Funcional de Seguridad

## Descripción
Toda comunicación entre el cliente y los servicios remotos debe protegerse mediante HTTPS.

## Requisitos Específicos

RNF-031.1 — En producción, las solicitudes que transporten datos de la aplicación deben usar HTTPS.

RNF-031.2 — Las conexiones HTTP deben redirigirse a HTTPS cuando la infraestructura lo permita.

## Verificación
Verificar la configuración TLS y revisar las solicitudes de red en producción.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
