# RNF-065 — Precisión de direcciones

**Tipo:** Requisito No Funcional de Calidad de datos

## Descripción
Las direcciones y ubicaciones sugeridas deben corresponder razonablemente con los resultados del servicio geográfico utilizado.

## Requisitos Específicos

RNF-065.1 — El objetivo de acierto de direcciones será al menos 95 % sobre un conjunto de pruebas representativo y previamente definido.

RNF-065.2 — Si el proveedor no devuelve un resultado fiable, la interfaz debe permitir corregir o confirmar la ubicación.

## Verificación
Comparar resultados de geocodificación con un conjunto de direcciones verificadas.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
