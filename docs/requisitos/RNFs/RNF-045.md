# RNF-045 — Optimización de imágenes

**Tipo:** Requisito No Funcional de Rendimiento

## Descripción
Las imágenes adjuntas a reportes deben optimizarse para reducir tiempos de carga y almacenamiento.

## Requisitos Específicos

RNF-045.1 — Las imágenes deben validarse por tipo y tamaño antes de aceptarse.

RNF-045.2 — Las vistas previas deben usar versiones optimizadas cuando sea posible, preservando la evidencia necesaria.

## Verificación
Subir imágenes de distintos tamaños y medir peso transferido y tiempo de visualización.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
