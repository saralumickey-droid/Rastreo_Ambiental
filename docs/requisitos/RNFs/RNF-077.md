# RNF-077 — Portabilidad de base de datos

**Tipo:** Requisito No Funcional de Mantenibilidad

## Descripción
El diseño de datos debe documentar las dependencias específicas del motor para facilitar futuras migraciones.

## Requisitos Específicos

RNF-077.1 — El esquema, las migraciones y los respaldos deben estar documentados y versionados.

RNF-077.2 — Las consultas y tipos específicos del motor deben identificarse para estimar el esfuerzo de migración.

## Verificación
Revisar scripts de migración y documentar las dependencias del motor de base de datos.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
