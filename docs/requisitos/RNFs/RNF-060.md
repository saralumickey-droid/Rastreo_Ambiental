# RNF-060 — Mensajes de error seguros

**Tipo:** Requisito No Funcional de Seguridad

## Descripción
Los mensajes mostrados al usuario deben explicar el problema sin revelar detalles internos.

## Requisitos Específicos

RNF-060.1 — Los errores de producción no deben exponer rutas del servidor, trazas, consultas, credenciales ni estructura interna.

RNF-060.2 — Los detalles técnicos necesarios para diagnóstico deben almacenarse en logs protegidos y con datos sensibles omitidos.

## Verificación
Provocar errores controlados y revisar la respuesta visible y el log interno.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
