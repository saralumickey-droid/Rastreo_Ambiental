# RNF-004 — Prevención de accesos no autorizados

**Tipo:** Requisito No Funcional de Seguridad

## Descripción
El sistema debe impedir el acceso a recursos y operaciones por parte de personas sin permisos válidos.

## Requisitos Específicos

RNF-004.1 — El backend debe comprobar la autorización en cada operación protegida; ocultar botones en el frontend no es suficiente.

RNF-004.2 — Las solicitudes no autorizadas deben responder con un código HTTP apropiado, como 401 o 403.

RNF-004.3 — Los errores no deben exponer rutas internas, consultas SQL, secretos ni detalles de configuración.

## Verificación
Intentar acceder directamente a endpoints y recursos con una cuenta no autorizada.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
