# RNF-012 — Claridad visual

**Tipo:** Requisito No Funcional de Usabilidad

## Descripción
Las pantallas deben presentar la información de manera clara, consistente y organizada.

## Requisitos Específicos

RNF-012.1 — Los títulos, botones, formularios y mensajes deben mantener estilos consistentes entre módulos.

RNF-012.2 — La información prioritaria de cada pantalla debe distinguirse de la información secundaria.

## Verificación
Revisar las pantallas principales y validar consistencia visual.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
