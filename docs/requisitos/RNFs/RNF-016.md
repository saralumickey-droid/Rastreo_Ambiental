# RNF-016 — Compatibilidad con navegadores

**Tipo:** Requisito No Funcional de Compatibilidad

## Descripción
La aplicación web debe funcionar en versiones actuales de navegadores ampliamente utilizados.

## Requisitos Específicos

RNF-016.1 — Las funciones principales deben probarse en versiones vigentes de Chrome, Edge, Firefox y Safari cuando aplique.

RNF-016.2 — La interfaz no debe depender de funciones experimentales sin alternativa compatible.

## Verificación
Ejecutar una lista de pruebas funcionales en los navegadores objetivo.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
