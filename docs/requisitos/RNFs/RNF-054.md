# RNF-054 — Validación de datos JSON

**Tipo:** Requisito No Funcional de Integridad

## Descripción
Los datos recibidos por la API deben validarse antes de procesarse o almacenarse.

## Requisitos Específicos

RNF-054.1 — Las solicitudes deben validarse mediante esquemas que definan tipos, campos requeridos, límites y formatos.

RNF-054.2 — Los datos inválidos deben rechazarse con mensajes controlados y códigos HTTP apropiados.

## Verificación
Enviar solicitudes con campos faltantes, tipos incorrectos y valores fuera de rango.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
