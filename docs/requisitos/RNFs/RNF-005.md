# RNF-005 — Control de acceso por roles

**Tipo:** Requisito No Funcional de Seguridad

## Descripción
El sistema debe aplicar permisos según los roles definidos para ciudadano, funcionario, conductor y administrador.

## Requisitos Específicos

RNF-005.1 — Cada rol solo debe ejecutar las operaciones autorizadas para sus responsabilidades.

RNF-005.2 — Los permisos deben validarse en el backend y mantenerse coherentes con la interfaz.

RNF-005.3 — Los cambios de rol deben quedar restringidos a usuarios autorizados y registrarse cuando corresponda.

## Verificación
Ejecutar pruebas de autorización para cada rol y cada módulo protegido.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
