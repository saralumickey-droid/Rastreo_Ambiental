# RNF-035 — Tamaño de aplicación móvil

**Tipo:** Requisito No Funcional de Eficiencia

## Descripción
Si se entrega una aplicación móvil instalable, su tamaño debe mantenerse dentro de un límite razonable.

## Requisitos Específicos

RNF-035.1 — El paquete de instalación de la versión de producción no debe superar 50 MB, salvo aprobación documentada.

RNF-035.2 — Si Rastreo Ambiental se distribuye únicamente como aplicación web, este requisito debe marcarse como no aplicable.

## Verificación
Medir el tamaño del paquete final de distribución.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
