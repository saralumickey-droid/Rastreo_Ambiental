# RNF-053 — Expiración de sesión

**Tipo:** Requisito No Funcional de Seguridad

## Descripción
Las sesiones deben expirar después de un periodo de inactividad para reducir el riesgo de uso indebido.

## Requisitos Específicos

RNF-053.1 — El tiempo objetivo de expiración por inactividad será de 30 minutos, salvo que el diseño de seguridad aprobado establezca otra política.

RNF-053.2 — Al expirar la sesión, las operaciones protegidas deben requerir autenticación nuevamente.

## Verificación
Comprobar el comportamiento después del periodo configurado y al intentar usar un token expirado.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
