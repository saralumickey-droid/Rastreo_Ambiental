# RNF-013 — Navegación sencilla

**Tipo:** Requisito No Funcional de Usabilidad

## Descripción
La navegación debe permitir llegar a las funciones principales con una estructura predecible.

## Requisitos Específicos

RNF-013.1 — Las opciones de navegación deben corresponder con el rol autenticado.

RNF-013.2 — El usuario debe poder identificar en qué módulo se encuentra y regresar a una sección anterior sin perder datos ya confirmados.

## Verificación
Probar recorridos habituales por cada rol.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
