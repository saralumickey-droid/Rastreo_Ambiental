# RNF-073 — Auditoría de dependencias

**Tipo:** Requisito No Funcional de Seguridad

## Descripción
Las dependencias del proyecto deben revisarse periódicamente para identificar vulnerabilidades conocidas.

## Requisitos Específicos

RNF-073.1 — El proyecto debe ejecutar una revisión automatizada de dependencias en el flujo de desarrollo o antes de cada versión.

RNF-073.2 — Las vulnerabilidades críticas o altas deben corregirse o documentarse con una mitigación antes del despliegue.

## Verificación
Ejecutar el auditor de dependencias disponible para el stack y revisar los resultados.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
