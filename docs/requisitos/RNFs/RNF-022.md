# RNF-022 — Dependencia de conexión a internet

**Tipo:** Requisito No Funcional de Conectividad

## Descripción
Las funciones que requieren servidor, mapas o geolocalización remota deben informar si no hay conectividad.

## Requisitos Específicos

RNF-022.1 — La aplicación debe detectar errores de conexión y comunicar que algunas funciones requieren internet.

RNF-022.2 — No debe indicar que una operación fue guardada si el servidor no confirmó su recepción.

## Verificación
Probar los flujos principales al desconectar y restablecer la conexión.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
