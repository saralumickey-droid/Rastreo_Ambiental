# RNF-003 — Autenticación

**Tipo:** Requisito No Funcional de Seguridad

## Descripción
El acceso a las funciones privadas de Rastreo Ambiental debe requerir autenticación.

## Requisitos Específicos

RNF-003.1 — Las rutas privadas del frontend y los endpoints protegidos del backend deben verificar que exista una sesión o credencial válida.

RNF-003.2 — Las credenciales incorrectas deben producir un mensaje genérico que no revele si una cuenta existe.

RNF-003.3 — La sesión debe finalizar al cerrar sesión y dejar de permitir el acceso a funciones protegidas.

## Verificación
Probar acceso sin iniciar sesión, con credenciales inválidas y después de cerrar sesión.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
