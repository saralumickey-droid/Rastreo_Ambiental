# RNF-072 — Analítica de uso

**Tipo:** Requisito No Funcional de Monitoreo

## Descripción
Las métricas de uso deben ayudar a mejorar el sistema sin recopilar datos personales innecesarios.

## Requisitos Específicos

RNF-072.1 — La analítica por pantalla solo debe activarse con una finalidad documentada y de acuerdo con la política de privacidad.

RNF-072.2 — Los informes deben priorizar datos agregados y restringir el acceso a métricas identificables.

## Verificación
Revisar eventos analíticos, datos enviados y permisos de acceso.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
