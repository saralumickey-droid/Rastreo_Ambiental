# RNF-036 — Compatibilidad Android

**Tipo:** Requisito No Funcional de Compatibilidad

## Descripción
Si se desarrolla una aplicación móvil nativa o híbrida, debe ser compatible con Android 8 o superior.

## Requisitos Específicos

RNF-036.1 — Las funciones soportadas deben probarse en Android 8 o superior.

RNF-036.2 — Si el producto es exclusivamente web, la compatibilidad se evaluará mediante navegador móvil y este criterio nativo será no aplicable.

## Verificación
Probar en dispositivos o emuladores Android dentro del rango objetivo.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
