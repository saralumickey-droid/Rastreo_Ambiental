# RNF-056 — Integración continua

**Tipo:** Requisito No Funcional de Mantenibilidad

## Descripción
Los cambios de código deben pasar verificaciones automáticas antes de desplegarse.

## Requisitos Específicos

RNF-056.1 — El flujo de integración continua debe ejecutar, como mínimo, verificaciones de compilación y pruebas configuradas.

RNF-056.2 — Los despliegues de producción deben bloquearse si fallan las verificaciones obligatorias.

## Verificación
Revisar la configuración del pipeline y probar un cambio que produzca un fallo controlado.

## Notas técnicas
- **Estado:** Por verificar.
- Los umbrales y tecnologías indicados son criterios propuestos; deben validarse frente a la arquitectura real de Rastreo Ambiental.
- Si una condición depende de una aplicación móvil nativa, un proveedor externo o infraestructura todavía no implementada, debe marcarse como **No aplicable** o **Pendiente de decisión**, con justificación.
